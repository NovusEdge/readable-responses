# Sources and limits

This skill contains original editorial guidance. It was designed for compact
engineering specs and usable software documentation. Its checklists are local
practice, not quotations or reconstructed clauses from paid standards.

## Public sources

- [International Plain Language Federation: What is plain language?](https://www.iplfederation.org/plain-language/)
  explains reader needs, navigation, comprehension, and practical use. This
  informs the reader-oriented approach; the skill is not a complete account of
  ISO 24495-1.
- [ISO 24495-1:2023 catalog page](https://www.iso.org/standard/78907.html)
  identifies the standard's scope. The full standard was not available when this
  skill was written. A preview does not establish the full requirements.
- [ISO/IEC/IEEE 26514:2022 catalog page](https://www.iso.org/standard/77451.html)
  identifies its scope as software-user information development, structure,
  content, and format. The full standard was not available. This skill's
  engineering-spec checks are a separate local adaptation.

Sources checked on 2026-09-04. Recheck editions and availability for a question
about current standards; routine editing does not require browsing these pages.

## Claims

Describe the result as reviewed for clarity, consistency, or the checks actually
performed. Do not claim ISO compliance, certification, completeness, clause-level
verification, or STE dictionary validation from this skill. Do not fabricate
clause numbers. No standard PDF or dictionary is bundled.

If the user supplies additional source material, distinguish requirements
verified in that material from local editorial preferences. Preserve the user's
chosen standard when explicitly requested and state any remaining verification
limits. This skill does not replace an existing specialist STE skill.
